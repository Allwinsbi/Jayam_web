# Construction 2 — Homepage Recreation

A responsive recreation of the XTRA Construction 2 WordPress theme homepage built with React and Vite.

**Live Demo:** https://jayamweb-five.vercel.app/

**Reference:** https://xtratheme.com/elementor/construction-2/

## Tech Stack
- React 18
- Vite 5
- CSS3 (Flexbox, CSS Grid, CSS Animations)
- Font Awesome 6 & Google Fonts (Poppins, Roboto)

## Features
- **Hero Slider with 3D Man Entry:** Multi-layer angled skew background with entrance animation, video modal trigger, and dual-ribbon banner slide.
- **Interactive Sections:** 3D card flips on feature cards, filterable projects gallery with lightbox modal, and testimonials carousel.
- **Sticky Navigation & Mobile Drawer:** Sticky desktop menu with search dropdown and slide-out navigation for smaller viewports.
- **Working Interactive Form:** Quote request form with state management, input validation, and user confirmation feedback.
- **Responsive Across Devices:** Tested layout adaptability across desktop, laptop, tablet, and mobile viewports.

## Run Locally

```bash
npm run dev
```
